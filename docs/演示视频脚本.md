# 演示视频脚本（2 分钟）
> 按答辩要求：成果演示 2 分钟，提前录制

## 录制准备
- 打开系统：http://<虚拟机IP>/（或开发环境 http://localhost:5173）
- 浏览器全屏，分辨率 1920×1080
- 准备一个测试文件（如 test_certificate.pdf）

---

## 分镜脚本

### 【0:00-0:15】系统总览
**画面**：浏览器展示登录页，短暂停留后点击"注册账号"
**旁白/字幕**：
> 本系统是基于联盟链的高校毕业生技能成果可信存证平台，支持学生、院校管理员、实训企业、招聘企业四类角色。

### 【0:15-0:35】注册 + 链账户自动生成
**画面**：填写注册表单（角色选"院校管理员"），点击注册
**关键展示**：弹窗显示"注册成功（已自动生成区块链账户）"及链账户地址
**旁白/字幕**：
> 注册时系统自动为用户分配区块链公私钥与链账户地址。

### 【0:35-0:55】成果录入 + 文件哈希
**画面**：登录后进入"成果录入"页面 → 填写成果信息 → 上传证书附件
**关键展示**：上传后自动显示 SHA-256 文件哈希
**旁白/字幕**：
> 上传附件后，系统自动计算文件 SHA-256 哈希，作为数字指纹。

### 【0:55-1:20】上链存证
**画面**：点击"上链存证" → 确认弹窗 → 显示存证编号、交易哈希、区块高度
**旁白/字幕**：
> 调用智能合约将哈希写入区块链，返回唯一存证编号，链上记录不可修改删除。

### 【1:20-1:50】凭证核验（核心演示）
**画面**：打开"外部企业核验入口"（/verify）→ 输入存证编号+正确文件哈希 → 显示"核验通过"
**然后**：修改文件内容（模拟篡改）→ 重新计算哈希 → 再次核验 → 显示"核验不通过（信息存在篡改风险）"
**旁白/字幕**：
> 企业输入存证编号核验：哈希一致则通过；文件被篡改时准确输出核验不通过——系统防篡改能力有效。

### 【1:50-2:00】收尾
**画面**：回到系统主界面或架构图
**旁白/字幕**：
> 系统实现了"成果上传→存证→企业核验"的完整可信闭环。谢谢观看。

---

## 录制注意事项
1. 操作要流畅，鼠标移动不要太快
2. 核验"不通过"的结果画面至少停留 3 秒
3. 可用 OBS Studio 录屏，输出 MP4
4. 全程开字幕（可用 OBS 的文本源或后期加）
5. 最后检查：文件不超过 100MB、时长 1:50-2:10
