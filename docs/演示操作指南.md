## 演示流程（按答辩顺序）

### 第一步：展示系统首页（30秒）
1. 打开浏览器访问 `http://<虚拟机IP>`
2. 展示登录页面，介绍系统名称
3. 点击「注册账号」展示四类角色选择 + 自动生成链账户

### 第二步：院校管理员录入成果（60秒）
1. 用 `admin01` 登录（登录页可点击「院校管理员」一键填充用户名与口令）
2. 进入「成果录入」→ 点击「+ 录入成果」
3. 填写**学生学号**（系统自动关联学生姓名），填写成果信息，上传一个文件（如图片/PDF）
4. **展示系统自动计算的 SHA-256 文件哈希**
5. 提交后点击「上链存证」→ 确认弹窗「上链后不可修改删除」
6. **展示存证编号、交易哈希、区块高度**

### 第三步：学生查看存证（30秒）
1. 退出，用 `demo_student` 登录
2. 进入「我的存证」
3. **展示链上存证凭证列表**（含存证编号、哈希、交易哈希）
4. 点击「二维码」展示凭证二维码（创意功能）

### 第四步：企业核验——篡改模拟（60秒）
1. 打开无痕窗口访问 `http://<虚拟机IP>/verify`（公开核验页）
2. **快速演示**：点击页头「填入演示数据」→ 开始核验 → 显示 **「核验通过（数据未篡改）」**
3. **篡改模拟**：点击「一键篡改演示」（或把哈希最后几位改掉，如改成 `...520bb9`）→ 开始核验
   → 显示 **「核验不通过（信息存在篡改风险）」**
4. **这就是防篡改的核心演示！**（也可用「复制核验链接」发给企业，扫码/点链接自动预填）

### 第五步：管理端检索与日志（30秒）
1. 用 `admin01` 登录
2. 进入「存证管理」→ 按姓名/学号检索
3. 进入「操作日志」→ 展示全部操作哈希留痕

## 系统架构（答辩讲解要点）

```
浏览器 → Nginx(80) → Vue3 前端
                 → Go 后端(8080) → MySQL(3306) + Ganache 链(8545)
                                    ↓
                              Solidity 合约
                        CredentialRegistry.sol
```

**技术栈**: Solidity 0.8.19 + Golang 1.21 + Vue3 + MySQL 8.0 + Ganache + Nginx

**防篡改原理**: 文件 SHA-256 哈希上链，核验时重新比对。哈希不一致 = 文件被篡改。

## 如果需要重新启动系统

在 CentOS7 终端执行:
```bash
# 1. 启动 Ganache
/usr/local/nodejs/bin/ganache --host 0.0.0.0 --port 8545 -i 1337 -a 10 -e 1000 --wallet.deterministic --db /opt/skill-credential/chain-data &

# 2. 启动后端
cd /opt/skill-credential/backend
export CONTRACT_ADDR=0xe78A0F7E598Cc8b0Bb87894B0F60dD2a88d6a8Ab
export CHAIN_RPC=http://127.0.0.1:8545
# 口令/私钥/密钥不写入仓库：由环境变量注入，或填写在本地文件 deploy/.env.demo 中
export DB_PASSWORD='<数据库口令>'
export DEPLOYER_KEY='<部署者私钥>'
export JWT_SECRET='<JWT 签名密钥>'
./skill-credential-server &

# 3. Nginx 已配置为开机自启，无需手动启动
```
